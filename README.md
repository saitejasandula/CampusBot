# CampusBot: AI Helpdesk Chatbot for College Students

Please see [`campusbot/README.md`](campusbot/README.md) for full project documentation, quickstart instructions, API references, architecture diagram, Render & Vercel deployment guides, and benchmark results.

### Quick Run & Deployment Options
- **Local Development**:
  - Backend: `cd campusbot/backend && .venv\Scripts\activate && uvicorn app.main:app --reload`
  - Frontend: `cd campusbot/frontend && npm install && npm run dev`
- **Cloud Deployment**:
  - Backend (Render): [`render.yaml`](campusbot/render.yaml)
  - Frontend (Vercel): [`vercel.json`](campusbot/frontend/vercel.json)
